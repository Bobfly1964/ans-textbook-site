# Факультатив: первый настоящий агент с инструментом чтения

Это **дополнительный**, необязательный для зачёта трек. `agents_sdk_readonly.py` использует официальный **OpenAI Agents SDK** и при запуске действительно обращается к внешнему API модели. Не путайте с `demo/offline_replay.py`, который не использует LLM и гарантированно запускается локально без ключей и сети.

## Перед запуском

1. На своём компьютере установите Python 3.11+ и создайте виртуальное окружение, если ещё не сделали этого.
2. Сверьте текущую документацию: https://openai.github.io/openai-agents-python/quickstart/ (в учебном пакете код проверен по структуре документации 14.10.2026).
3. Установите зависимость: `python -m pip install openai-agents`.
4. Установите `OPENAI_API_KEY` **только** в переменной окружения вашей собственной системы. Никогда не записывайте ключ в `.md`, `.py`, Git или рабочую тетрадь.
5. Разберитесь с доступными тарифами, политиками передачи данных, условиями обработки и лимитами вашей учётной записи. **Запуск может быть платным**.
6. Запустите из корня комплекта: `python optional_live/agents_sdk_readonly.py`.

## Что именно безопасно ограничено в этом учебном примере

Инструмент `get_training_cases()` способен прочитать только **один** абсолютный путь, вычисляемый от папки пакета. Модель не получает доступных функций редактирования, отправки почты, платежей, CRM и запуска команд. Это ограничение **предоставленного набора инструментов**, а не юридическая гарантия безопасности внешнего API. Локальная Python-программа также не умеет изменять другие файлы через предоставленные модели функции.

**Не включайте** в эту демонстрацию настоящий клиентский файл или иные источники. Пользователь сам решает, запускать ли пример. Перед любой реальной интеграцией необходимы отдельная оценка прав, обработка ошибок, журналирование и тесты.

## Что записать в отчёте

Запишите `run_mode=LIVE_AGENT`, дату, модель/версию среды (если видны), фактически полученный ответ, три проверенных ID/цитаты, ошибки, статус приёмки человеком и факт возможного расхода API. Не копируйте секреты или идентифицирующие сведения из логов. Наличие ответа SDK **не подтверждает** готовность сервиса к реальному бизнесу.

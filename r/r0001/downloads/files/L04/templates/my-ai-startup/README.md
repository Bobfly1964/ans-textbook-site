# Файлы сквозного проекта · Урок 04

Добавьте `13–17` к файлам `01–12` из предыдущих занятий. **Не заменяйте исходные документы новыми шаблонами.** Здесь содержатся только шаблоны текущего урока и переносимый текст роли в `agent/`.

- `13_agent_role_card.md`: роль и режим (ручной/агент/офлайн).
- `14_agent_task_contract.md`: восемь частей задачи.
- `15_agent_tool_policy.md`: права и stop-rule (реальные ограничения требуют настройки инструментов).
- `16_agent_run_log.csv`: журнал фактически проведённых упражнений.
- `17_agent_review.md`: человеческая проверка по ID и цитатам.
- `agent/AGENT_INSTRUCTIONS.md`: шаблон инструкции, не автоматический Skill и не исполняемый конфиг.

**Статус исходных учебных данных — SYNTHETIC.** Никакие ключи, реальные клиентские данные, записи разговоров и пароли не добавляйте в общую учебную папку или Git. На уроке 05 отдельные подтверждённые повторяемые приёмы станут Skills.

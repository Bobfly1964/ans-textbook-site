## 2. Проверенные внешние технические источники

### 2.1. OpenAI Agents SDK — определение агента и инструменты

**Ссылка:** https://openai.github.io/openai-agents-python/  
**Быстрый старт:** https://openai.github.io/openai-agents-python/quickstart/

**ВЕРИФИЦИРОВАНО:** настройка агента включает модель и инструкции; агенты могут получать функции-инструменты; SDK поддерживает вызовы инструментов, ограничения, делегирование, трассировку, человеческое подтверждение. Текущий официальный пример использует `from agents.decorators import tool` и `@tool`. Код в `optional_live/` написан согласно этой документации на дату проверки.

**Не означает:** каждый чат является самостоятельным фоновым агентом; инструмент существует, если он только назван в тексте; SDK автоматически гарантирует корректность результата; выполнение API бесплатно.

### 2.2. OpenAI Agents API — варианты исполнения

**Ссылка:** https://developers.openai.com/api/docs/guides/agents  
**Ссылка на конфигурацию:** https://developers.openai.com/api/docs/guides/agents-api/configuration

**ВЕРИФИЦИРОВАНО:** различают управляемые сессии, Agents SDK и прямое управление через Responses API; состояние и полномочия зависят от выбранного runtime и окружения. Практика первого урока с ручной передачей данных отличается от программного исполнения.

### 2.3. Claude Code — субагенты и права

**Ссылка:** https://code.claude.com/docs/en/sub-agents  
**Ссылка:** https://code.claude.com/docs/en/permissions  
**Ссылка:** https://code.claude.com/docs/en/memory

**ВЕРИФИЦИРОВАНО:** проектные подагенты могут иметь собственные инструкции, отдельный контекст и ограниченные инструменты; существуют режимы разрешений, включая режим чтения/планирования. Детали функций, режимов, названий файлов и загрузки памяти зависят от текущих версий. Не следует отключать запросы подтверждений ради удобства.

### 2.4. OpenAI Codex: постоянные инструкции — не бесконечный список запретов

**Ссылка:** https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra  
**Дата публикации:** 11 сентября 2026 года.

**ВЕРИФИЦИРОВАНО:** рекомендации по инструкции для Codex и Agent Skills делают акцент на краткости, контекстной загрузке и пересмотре устаревших правил. Для урока 04 это аргумент в пользу узкого контракта вместо многостраничного «ИИ-директора».

### 2.5. Model Context Protocol — безопасность подключённых инструментов

**Ссылка:** https://modelcontextprotocol.io/specification/2025-11-25/basic/security_best_practices  
**Ссылка:** https://modelcontextprotocol.io/docs/2025-11-25/tutorials/security/security_best_practices

**ВЕРИФИЦИРОВАНО:** меры безопасности и минимизация полномочий необходимы при подключении инструментов, работе с удалёнными сервисами и недоверенными вводами. Мы используем упрощённый безопасный пример: отсутствие лишних инструментов вместо текстового обещания «не пользоваться ими».

## 3. Какие сведения придуманы специально для курса

- Ирина и Максим, их стартап и все коммерческие реплики — **УЧЕБНЫЙ ПРИМЕР**.
- Все `C...` и `X...` строки CSV — **SYNTHETIC**, не реальные обращения или преступные инциденты.
- Точное распределение 8/5/3/2/2 создано в уроке 03 для демонстрации и не является оценкой рыночных частот.
- Один агент + один человек — **МЕТОДИЧЕСКОЕ РЕШЕНИЕ** для простого старта, не обязательная организационная норма.
- Контракт из восьми частей и 10-балльная рубрика — **МЕТОДИЧЕСКОЕ РЕШЕНИЕ**.
- Гипотезы о плохом интерфейсе и причинах обращений — **ГИПОТЕЗЫ**, пока не проверены реальным исследованием или экспериментом.

## 4. Разграничение трёх демонстрационных режимов

| Файл/процедура | Что происходит | Чего нельзя утверждать |
|---|---|---|
| `demo/offline_replay.py` | Детерминированный Python читает синтетический CSV и строит шаблонный отчёт | «ИИ провёл анализ» |
| Чат-сессия по P01–P04 | Человек вручную передаёт учебный CSV модели и проверяет её ответ | «Система сама работает на фоне», «реальный рынок проверен» |
| `optional_live/agents_sdk_readonly.py` | При явном запуске OpenAI SDK обращается к API модели и имеет один read-only tool | «Есть право на реальные данные», «всё проверено», «нет расходов» |
